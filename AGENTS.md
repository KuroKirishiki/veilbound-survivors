# Character art requirements

The user requires every future playable character to match the FIRST FOUR heroes (Elian, Alder, Nyx, Satoru). This is the permanent visual direction.

- Use the existing heroes-animation.png and sorcerer-animation.png as visual references.
- Detailed hand-painted fantasy RPG sprites, textured cloth, leather, metal and hair; realistic adult proportions and miniature painterly rendering.
- Do not substitute flat vector polygons, geometric Canvas dolls, chibi or cartoon sprites for final character art.
- New heroes must have matched menu portraits, preparation/release/recovery poses and independent moving legs. Transformation forms follow the same rendering style.
- Keep sprite files local and include them in the offline cache.
- Preserve recognizable identity details without changing the shared rendering style.
- champions-painted.webp is the approved style for David and Lyra.
